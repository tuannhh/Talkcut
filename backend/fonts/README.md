# Bundled title fonts

Google Sans v14.000 static release: https://github.com/googlefonts/googlesans/releases/tag/v14.000
Open Sans, Barlow and Roboto: https://github.com/google/fonts/tree/main/ofl (downloaded 2026-09-09).
Each family includes its upstream OFL license. Files are used locally by Pillow for identical preview/export text. Variable weights are set explicitly to 400/700, retaining default width. Existing clips keep DejaVu Sans unless another font is selected.
